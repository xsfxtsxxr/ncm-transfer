    解析容器

    读取 NCM 头部，取出加密的 RC4 密钥 与歌曲元数据（歌名、歌手、专辑、封面）。

    本地解密

    用 AES-128-ECB 还原密钥，再对音频流做逐字节流解密，得到原始音频数据。

    03

    按需输出

    选「原格式」直接还原原始音频（无损、最快）；也可以指定转成 MP3（可选码率）或 FLAC。

    使用须知

    • 文件不会离开你的设备。所有解密运算都在这一个页面里用 JavaScript 完成，没有后端接口，断网也能正常使用。
    • 「原格式」不转码。直接还原原始音频，音质与文件逐字节一致，速度也最快，日常推荐。
    • 转码只在需要时发生。目标格式与源相同（如 FLAC → FLAC）会自动直通、不重新编码；只有跨格式（如 FLAC → MP3）才会解码后重新编码，MP3 → FLAC 属于有损转无损，不会提升音质、体积反而变大。
    • 请仅处理你有权使用的文件。本工具用于把已下载的会员/自有音乐还原为通用格式以便在其它设备播放，请勿用于传播或商业用途。
    • 大文件会稍慢。解密速度约为每秒数十 MB，转换时进度条会在每个文件上实时显示。
